    Properties

    Select a box on the label to change its font, alignment, size and position.

    • Drag a box to move it; drag its handles to resize.
    • Drag the round handle above a box to rotate it (Shift for 15° steps).
    • Double-click a text box to edit it in place.
    • Select several boxes with Ctrl/Cmd/Shift+click, or drag a rectangle across the label. Ctrl/Cmd+G groups them so they move together.
    • To style a few words, select them while editing a text box and press Ctrl/Cmd+B, I or U.
    • Ctrl/Cmd+C, X and V copy, cut and paste boxes; Ctrl/Cmd+B, I and U make the selected text bold, italic or underlined.
    • Arrow keys nudge the selected box (hold Shift for bigger steps).
    • Type {{Column}} to mix merge fields with plain text, e.g. {{City}}, {{State}} {{Zip}}.
    • Conditional text: {{#Nickname}} ({{Nickname}}){{/Nickname}} appears only when Nickname has a value; use {{^Nickname}}…{{/Nickname}} for text shown only when it is empty.
    • When printing, choose Actual size / 100% scale and no margins.
